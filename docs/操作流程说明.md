# 微信客户沟通记录提取与总结工具 —— 操作流程说明

> 本工具用于把你与客户的微信聊天记录，自动整理成一篇篇「客户沟通总结」，并导出为 Excel。
> 支持两种生成方式：**本地生成（不联网、数据不外发）** 和 **AI 生成（需联网 + API 密钥）**。

---

## 一、安装与启动

- **Windows 全新系统**：双击 `微信客户沟通总结工具_Setup.exe` → 选择安装目录 → 勾选桌面/开始菜单快捷方式 → 安装完成。
- **已有便携版**：直接双击 `启动工具.exe` 即可打开。
- 打开后主界面从上到下分为 **①来源 → ② 勾选 → ③ 时间 → ④ 方式 → ⑤ 导出位置 → ⑥ 结果** 六个区域。

---

## 二、主流程（六步）

### ① 选择聊天记录来源
左上角下拉框选一种来源，然后按提示选文件/路径：

| 数据源 | 适用场景 | 你需要准备什么 |
|---|---|---|
| **直接读取本机微信（Windows 4.x）** | 日常主力，自动读本机微信加密库 | 微信保持**登录状态**，首次自动抓取一次数据库密钥 |
| **内置样例数据** | 试用 / 培训 / 验收格式 | 无，免配置 |
| **导入已导出的聊天记录文件** | 推荐·跨平台·合规 | 把记录导出成 csv/txt/json 或整包 .zip（导出途径自行掌握），选那个文件或文件夹 |
| **读取已解密的微信数据库** | 已有解密库的场景 | 选已解密的 .zip 或文件夹（内含 MicroMsg.db / MSG*.db）|

选中后点 **「浏览…」** 指定数据路径；`wx4` 数据源无需选路径，会自动探测本机微信账号。

### ② 勾选聊天对象
点 **「加载聊天对象」** → 下方出现客户列表。
- 顶栏可**搜索**，搜索不会清空已勾选；
- **点任意一行**即可勾选 / 取消；也可用 **全选当前列表 / 取消当前列表 / 清空全部勾选**；
- 对象很多时点 **「独立窗口选择…」** 大屏多选；
- 左侧「我方标识名」可填你的称呼（多个逗号分隔），用于群聊归人校正。

### ③ 设置提取时间范围
右侧选快捷区间（近 7/30/90/180/365 天等），或手动填 **开始日期 / 结束日期**（格式 `2026-08-01`，含首尾两天）。所选每个对象各生成一篇总结。

### ④ 选择总结生成方式
- **智能（推荐）**：优先用 AI，不可用时自动改用本地总结；
- **仅用 AI**：质量最好，需联网与 API 密钥；
- **仅用本地**：不联网、数据不外发。

下方可设 **总结字数区间**（默认 50~200 字）与 **客户阶段**（如续费期、稳定使用等，影响总结侧重；留空则按对话关键词自动推断）。
点 **「AI 设置…」** 配置 AI（见第三节）。

### ⑤ 设置 Excel 保存位置
点 **「另存为…」** 选择导出文件（默认 `微信客户沟通总结.xlsx`），并选 **追加到已有文件（推荐）** 或 **覆盖重建**。

### ⑥ 开始提取并生成总结
点底部 **「开始提取并生成总结」** → 完成后下方结果表格显示每篇总结（列：客户名称 / 时间范围 / 总结内容 / 字数方式）。
- **双击任意一行**可人工修订文字，改完再保存；
- 点 **「导出到 Excel」** 保存（Excel 固定三列：客户名称 / 时间范围 / 总结内容）；
- **「打开 Excel 文件」** 直接查看；**「清空结果」** 只清界面，不影响已导出文件。

## 三、AI 总结设置（可选）

菜单 **设置 → AI 总结设置**：
- **模型来源**：
  - **WorkBuddy 模型**：点「刷新」拉取你本机已配置的模型（kimi / deepseek / doubao 等），选中即可用，**无需手填地址与密钥**；
  - **手动填写**：填任一 OpenAI 兼容接口（默认月之暗面 Kimi），含接口地址、模型名、API Key。
- **思考深度**：短总结（50–200 字）建议选**关闭**，可降低延迟与消耗；仅推理模型识别此参数。
- 密钥保存在本机用户目录（`%USERPROFILE%\.wxcsm\config.json`），**不会随工具分发**；也可用环境变量注入（`MOONSHOT_API_KEY` / `OPENAI_API_KEY` / `WXCSM_API_KEY`，优先级更高）。
- **没有 API Key 也能用**：第④步选「智能」或「仅用本地」，零配置、断网可用，只是文字不如 AI 顺滑。

---

## 四、微信 4.x 直读使用要点

- **首次**：确保微信已登录并运行 → 选「直接读取本机微信」数据源 → 点「加载聊天对象」，工具自动做**只读内存扫描**抓取密钥（无注入、无重启、无网络外发），并**DPAPI 加密缓存**到本机。
- 缓存后即使微信退出，也能**离线**解密读取。
- 若账号退出重登换了密钥，工具会检测到并提示重新抓取。
- 仅能取到**当前活跃账号**；非活跃历史账号需切到该账号后再抓。

---

## 五、合规与安全提示

- 提取客户沟通记录前，请确认已获公司授权，并遵守个人信息保护规定与客户约定。
- 选「仅用本地」时，聊天内容**不会离开本机**；选 AI 时，内容会发给所配的 AI 接口。
- 本工具仅自动读取**已导出/已解密/本机授权**的数据，不注入微信进程、不外传任何密钥。

## 六、命令行方式（可选）

```bash
python cli.py list-sources                          # 查看可用数据源
python cli.py wx4-capture                            # 抓取数据库密钥（需微信运行中）
python cli.py list-contacts --source wx4             # 列出联系人
python cli.py run --source demo --all --preset 30d --out 总结.xlsx
python cli.py run --source wx4 --all --preset 30d --out 总结.xlsx
```

## 七、常见问题

- **点「开始提取」没反应/无结果**：先确认 ① 已加载对象、② 已勾选至少一个、③ 时间范围有数据。
- **选了「仅用 AI」却没填 Key**：会提示先到「设置 → AI 总结设置」填写。
- **AI 不可用自动降级**：提示改用本地总结，可用但文字略简。
- **wx4 读不到账号**：确认微信已登录、版本为 4.x，且数据目录可访问。
